# MovAi

Create images, videos and 3D designs with free APIs — no payment needed.

- **Images:** Pollinations (no key), Puter.js, Cloudflare Workers AI, Gemini, Hugging Face
- **Videos:** NovAI (CogVideoX Flash), Magic Hour, Puter.js, Hugging Face, Tavus
- **3D Design:** Hunyuan3D (in-page generation, GLB download), Masterpiece X
- **Settings:** Khmer / English, font size 0–100%, 7 app colours, Dark / Light / Auto mode, glass (clear / frosted / shine) sliders, text shadow colours, brand-name effects
- **Privacy:** API keys are stored only in your browser (localStorage) and are never sent anywhere except when generating.

## Run

Static single-page app — open `index.html` directly, or serve it:

```bash
npx serve .
```

## Deploy (Render static site)

Connect this repo in the Render dashboard as a **Static Site** (or use the
`render.yaml` Blueprint). Publish directory is the repo root.

Live site: https://movai.onrender.com (once deployed)
